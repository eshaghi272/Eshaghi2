# 💎 کلینیک زیبایی

سیستم مدیریت کلینیک زیبایی - پروژه کامل با فرانت‌اند و بک‌اند

## 🚀 ویژگی‌ها

- مدیریت بیماران، پزشکان و نوبت‌ها
- ثبت و مدیریت درمان‌ها
- داشبورد اختصاصی برای هر نقش (ادمین، پزشک، منشی، بیمار)
- گزارش‌گیری مالی
- گالری تصاویر
- فرم تماس و پیام‌رسانی

## 🛠️ تکنولوژی‌ها

### فرانت‌اند
- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router v6
- React Query
- Axios
- React Hot Toast
- Chart.js

### بک‌اند
- Node.js + Express
- TypeScript
- SQLite (Better-SQLite3)
- JWT Authentication
- Bcrypt

## 📦 نصب و اجرا

### پیش‌نیازها
- Node.js 16+
- npm یا yarn

### نصب وابستگی‌ها

```bash
# کلون کردن پروژه
git clone https://github.com/YOUR_USERNAME/beauty-clinic.git
cd beauty-clinic

# نصب وابستگی‌های بک‌اند
cd backend
npm install

# نصب وابستگی‌های فرانت‌اند
cd ../frontend
npm install
